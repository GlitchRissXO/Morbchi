# Morbchi

A macOS desktop pet companion with a cozy gothic whimsical soul.

A Tamagotchi inspired pet app built in Swift/SwiftUI. Your magical creature companion floats on your Mac desktop in a transparent window. Care for it, watch it evolve, decorate its room, and play mini-games together. It watches when you're working and stays quiet. It gets chatty and wandery when you step away.

**Aesthetic:** Dark academia meets cottagecore witch  deep plums, candlelight amber, moon motifs, and soft creature animations.

**Platform:** macOS 14+ · SwiftUI · AppKit · SwiftData · WeatherKit · Claude API
